## End-to-End Data Pipeline for Music Streaming Analytics  
**Date:** October 2025  
**Source:** DeepLearning.AI Data Engineering Capstone Project  

### Objective  
Build a complete, scalable data pipeline for analyzing music streaming events using modern cloud data engineering principles and industry-grade tools.

### Architecture & Tools  
- **AWS Glue** for data ingestion and ETL  
- **Amazon Redshift** as the analytical data warehouse  
- **Terraform** for infrastructure provisioning  
- **Apache Airflow** for orchestration and automation  
- **DBT** for transformation and dimensional modeling  
- **Star Schema** design for optimized analytical queries  
- **Medallion Architecture** (Bronze → Silver → Gold layers)

### What I Built  
- Ingestion pipelines to extract and load raw event data  
- Transformation layers with DBT for quality and normalization  
- Star-schema fact and dimension tables for analytics  
- Automated daily orchestrations using Airflow DAGs  
- Real-time insights for music trends, user sessions, and streaming performance

### Key Outcomes  
- End-to-end automated cloud pipeline  
- Scalable ETL architecture following Lakehouse principles  
- Business-ready analytics enabling trend detection and consumption insights
